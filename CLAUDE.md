## The game
Physics co-op party game. Pigs escape a barn before farmer **Bob** puts them on the grill.
2 local players (gamepads or a shared keyboard), online via **Steam Remote Play Together** (streams host screen → single shared screen, no split-screen).

## Tech
- Unity **6000.6.3f1**, URP (PC_RPAsset), 3D physics, **Input System only** (activeInputHandler=1).
- Installed: AI Navigation (NavMesh — for Bob), Input System, URP, Timeline, uGUI. No Cinemachine (own camera).
- Unity 6 API: `rb.linearVelocity` / `linearDamping` (not `velocity`/`drag`), `PhysicsMaterial` (not `PhysicMaterial`), avoid `FindObjectOfType`.
- Code: namespace `Porkour`; runtime in `Assets/Scripts/`, editor tools in `Assets/Editor/`.

## Decisions
- One shared screen + `PartyCamera` (Remote Play Together streams one screen).
- Physics movement on a single Rigidbody (capsule along Z, rotation X/Z frozen, zero-friction material). Ragdoll/wobble comes in stage 6.
- Own input asset with split-keyboard schemes → stage 2 spawns players via `PlayerInput.Instantiate(prefab, controlScheme, pairWithDevice)`.
- Builder **overwrites** Pig prefab & TestBarn scene → tuned values go into code defaults, not the prefab.
- Placeholder art = Unity primitives (pink pig). Real art later.

## Roadmap

5. **Full game loop (MVP)** — menu, level, escape exit = win, grilled = lose, restart.
6. **Polish** — active ragdoll/wobbly pigs, animation, sound, VFX, UI.
7. **Steam** — Steamworks (app ID), Remote Play Together, build.
